# Nutrition Calculator

A Python GUI application for calculating and planning nutrition intake using tkinter.

**Author:** AS3AD  
**Repository:** https://github.com/yousefas3ad/Project

## Features

- User-friendly nutrition calculation interface
- Beautiful and intuitive UI design
- Built with Python and tkinter

## Setup

### Prerequisites

- Python 3.14.2+
- Virtual environment

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yousefas3ad/Project.git
cd Project
```

2. Create and activate virtual environment:
```bash
python -m venv venv
source venv/Scripts/activate  # On Windows: venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Run the application:
```bash
python app.py
```
